# REALTIME GROUNDWATER MONITORING APP - CHATBOT CONTEXT

## APP OVERVIEW
**App Name**: Realtime Groundwater Analytics
**Purpose**: A comprehensive groundwater monitoring and analytics mobile application built with React Native and Expo
**Target Users**: Government officials, water management authorities, farmers, researchers, and the general public
**Organization**: Central Ground Water Board (CGWB), India

## TECHNICAL ARCHITECTURE

### Framework & Platform
- **Framework**: React Native with Expo (~53.0.22)
- **Navigation**: Expo Router (~5.1.5) with drawer navigation
- **Platform Support**: iOS, Android, and Web
- **State Management**: React Context API
- **Internationalization**: React i18next (supports 10+ Indian languages)
- **Maps**: React Native Maps with Google Provider
- **Charts**: React Native Chart Kit for data visualization
- **Storage**: AsyncStorage for local settings and data

### Key Dependencies
- @google/generative-ai: For AI-powered insights and chat functionality
- expo-location: For GPS location services
- expo-localization: For multilingual support
- react-native-maps: For interactive mapping features
- react-native-chart-kit: For data visualization charts
- @react-navigation/drawer: For side drawer navigation

## APP STRUCTURE & NAVIGATION

### Main Layout
- **Root Layout**: Stack layout with Settings and Notification providers
- **Navigation**: Drawer-based navigation with 8 main sections
- **Header**: Persistent header with logo, menu, language selector, and notifications
- **ChatBot**: Always-accessible floating chat interface

### Navigation Sections (Drawer Menu)
1. **Home** - Landing page with hero carousel and quick access
2. **Dashboard** - Real-time data overview and monitoring
3. **Groundwater Monitoring** - Detailed station-wise monitoring
4. **Predictions** - AI-powered forecasting (currently in development)
5. **Analytics** - Weather data integration and AI insights
6. **Maps** - Interactive station mapping with 31,574+ stations
7. **Reports** - Data export and report generation
8. **Settings** - User preferences and configuration

## TROUBLESHOOTING GUIDE

### Common Issues
1. **Location not detected** → Enable GPS and location permissions
2. **Charts not loading** → Check internet connection, refresh data
3. **Language not applying** → Restart app after language change
4. **Export failing** → Verify storage permissions and available space
5. **Notifications not working** → Enable notifications in device settings

### Performance Tips
- Regular cache clearing for optimal performance
- Close background apps for better memory management
- Update app regularly for latest features
- Use WiFi for data-heavy operations

### Feature Limitations
- Predictions feature under development
- Some rural stations may have delayed data
- Export size limited by device storage
- AI insights require internet connection
